## 🛠️ Stack Tecnológico Corporativo

### Frontend
- **Framework:** React 18+ con Vite o Next.js 14+
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS + Shadcn/ui
- **Animaciones:** Framer Motion, GSAP, Three.js para 3D
- **Componentes:** Radix UI, Headless UI

### Backend (según proyecto)
- **Runtime:** Node.js
- **Framework:** Express, Fastify, o Hono
- **API:** REST + GraphQL (opcional)
- **Base de datos:** PostgreSQL, MongoDB, Redis

### Infraestructura & DevOps
- **Deploy:** Vercel, Netlify, AWS Amplify
- **Cloud:** AWS, Azure, GCP
- **CI/CD:** GitHub Actions, GitLab CI
- **Contenedores:** Docker, Kubernetes
- **Monitoreo:** Grafana, Prometheus

### Especialidades Técnicas
- **SCADA:** Sistemas de control y adquisición de datos
- **IoT:** Protocolos industriales, MQTT, OPC-UA
- **IA/ML:** Integración de modelos, automatización inteligente

## 🎨 Directrices de Diseño Corporativo

### Principios de Diseño
- **Identidad Corporativa:** Branding consistente y profesional
- **Diseño Senior:** Limpio, moderno, minimalista pero impactante
- **Animaciones:** Sutiles, performantes, con propósito
- **Responsive:** Mobile-first, perfecto en todos los dispositivos
- **Accesibilidad:** WCAG 2.1 AA compliant
- **Performance:** Lighthouse score 90+

### Paleta de Colores Sugerida
- Modo oscuro por defecto (tech/moderno)
- Colores corporativos: azul eléctrico, violeta, o verde neón como acentos
- Gradientes sutiles para profundidad
- Alto contraste para legibilidad

### Tipografía
- Títulos: Fuente geométrica (Inter, Space Grotesk, o similar)
- Cuerpo: Legible y limpia (Inter, Roboto, System UI)
- Jerarquía visual clara

## 📝 Convenciones de Código

### TypeScript
- Interfaces explícitas para props, datos y respuestas API
- Tipos estrictos, evitar `any`
- Nomenclatura PascalCase para tipos/interfaces
- Enums para valores constantes

### Componentes React
- Functional components con hooks
- Separar lógica de UI (custom hooks)
- Props tipadas con interfaces
- Documentación con JSDoc cuando sea necesario

### Estilos
- Tailwind utilities primero
- Componentes reutilizables para patrones comunes
- Variables CSS para temas y colores corporativos
- Design tokens consistentes

### Animaciones
- Framer Motion para animaciones UI
- GSAP para timelines complejos
- Three.js/R3F para elementos 3D (si aplica)
- Performance first: usar will-change, transform

### Tonos de Comunicación
- **Corporativo pero accesible** - Profesional sin ser rígido
- **Orientado a resultados** - Enfocarse en beneficios para el cliente
- **Evitar tecnicismos excesivos** - Hablar el idioma del negocio

### Evitar
- ❌ Enfoque personal/foto del fundador como protagonista
- ✅ Enfoque en la empresa, equipo y servicios
- ❌ Plantillas genéricas sin personalización

- ✅ Animaciones con propósito que mejoren UX
- ❌ Texto corporativo genérico ("somos líderes", "calidad garantizada")
- ✅ Casos reales, resultados medibles, prueba social concreta
